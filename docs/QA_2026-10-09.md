# BALL 001 — Independent QA and scientific evidence register

**Audit date:** 2026-10-09  
**Scope:** source inspection of the default GitHub branch, particularly the CalculiX pressure-envelope, material sweep, FRD parser, model decision constants, test suite and project README.  
**Evidence classification:** SOURCE-INSPECTED is not EXECUTED, VERIFIED, or PHYSICALLY VALIDATED. Do not report source review as an independent solver run.

## Immediate remediation in this PR

- Reject NaN, infinity, zero and negative pressure inputs rather than allowing nonfinite quantities into exported CalculiX decks.
- Reject unsafe case labels before they are interpolated into solver file paths.
- Validate pressure-envelope material parameters through the existing stiffness-case guard.
- Reject nonfinite modulus, Poisson ratio and static increment inputs in the shared stiffness model.
- Add regression tests for invalid pressure, labels and material modulus.

These changes are **source-level safeguards**. They do not prove that the working finite-element model is correct, that a particular simulation converged, or that physical prototype behavior has been validated.

## Evidence gates for the baseline release (08M)

1. **Code gate:** unit/regression tests and style checks pass at a specific commit.
2. **Artifact gate:** independent replay creates a complete manifest with expected run identifiers, input/output hashes, solver version and nonempty files.
3. **Numerical gate:** geometry/mesh checks, case-aware solver convergence, result integrity and quantities-of-interest convergence are documented.
4. **Scientific gate:** analytical benchmark and model-form limitations are explicitly reviewed; no quantitative physical-performance claims without measurements.
5. **Product gate:** reference-ball and prototype comparative testing, setter-facing metrics, durability and circularity are separately labeled as measured, simulated, planned or unknown.

### Non-release conditions

Do not represent the project as a validated physical ball, verified superior circular architecture, completed FEniCSx/ANSYS cross-solver comparison or completed CFD study without the corresponding committed traceable evidence. The prior Warp installation/CPU smoke execution is not itself a BALL 001 kernel validation.
